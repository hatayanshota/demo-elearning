あなたはIT企業の提案資料作成の専門家です。以下のシステム情報をもとに、スクール運営者向けの「見積書（提案書）」を作成してください。

## 出力フォーマット
- Markdown形式
- 表形式を多用し、意思決定者（非エンジニア）が直感的に理解できる構成
- 金額は税別・税込を両方明記
- 各フェーズに「何が完成するか」をビジネス言語で記載（技術用語の羅列ではなく、業務効果を記載）

## 出力してほしい内容

上記の情報をもとに、以下の構成で「SchoolOS 開発見積書（提案書）」を作成してください:

1. **表紙情報** — 提出先（スクール運営者様）、提出元（開発会社）、作成日（2026年3月23日）、有効期限（30日間）
2. **エグゼクティブサマリー** — 3〜4行で「何を・いくらで・いつまでに」を要約
3. **プロジェクト概要** — SchoolOSとは何か、何を解決するか
4. **開発済み資産の価値** — Phase A完了済みの事実と、デモとして既に動作する機能の一覧。クライアントに「ここまで出来ている」ことの安心感を伝える
5. **見積り内訳**
   - Phase B（バックエンド）: 工数表 + 各項目の業務的意味
   - Phase C（テスト）: 工数表 + 品質保証の重要性
   - Phase D（デプロイ・オプション）: 工数表 + 「いつでも追加可能」の柔軟性を強調
6. **費用総括** — 3パターン提示:
   - パターンA: Phase B + C のみ（ローカル動作確認まで）
   - パターンB: Phase B + C + D（本番公開まで）
   - パターンC: Phase B + C + D + 保守（月額）
7. **スケジュール** — ガントチャート風の表（Week単位）
8. **ランニングコスト** — 規模別の月額コスト比較表
9. **他社比較** — 差別化ポイント表（★マーク付き）
10. **納品物一覧**
11. **前提条件・注意事項**
