以下をClaudeにコピペして使用してください。

```
あなたはIT企業の提案資料作成の専門家です。以下のシステム情報をもとに、スクール運営者（営業先）向けの「機能説明書」を作成してください。

## 出力フォーマット
- Markdown形式
- 各機能は「概要 → 画面イメージの説明 → 具体的な操作フロー → 活用シーン」の構成で記載
- 専門用語は避け、スクール運営者が直感的に理解できる平易な日本語で記述
- 競合との差別化ポイントには「★」マークを付与

## システム基本情報

- **システム名:** SchoolOS
- **用途:** スクール運営に特化したオールインワンLMS（学習管理システム）
- **ロール:** 管理者（スクール運営者）/ 講師 / 生徒 の3ロール
- **テーマ:** Webマーケティングスクール「GROWTH ACADEMY」をモデルケースとしたデモ

## 各画面の実装済み機能詳細

### 画面1: ロール選択（/）
- 画面中央に管理者・講師・生徒の3枚のカードを横並び表示
- 各カードにロール名と説明文（「スクール全体のKPIを分析」「課題のレビュー・フィードバック」「コース学習・セミナー参加」）
- カードクリックで各ロールのトップ画面へ遷移
- ヘッダーにロール切替ボタンを常設し、どの画面からでも別ロールに切替可能

### 画面2: KPIダッシュボード（/admin/dashboard）
**8つのKPIサマリーカード（4列×2行グリッド）:**
1. 在籍生徒数 — 全生徒のカウント
2. 新規入会者数（今月）— 当月入会者のカウント
3. アクティブ率（%）— 直近30日にログインした生徒の割合
4. 平均課題完了日数 — 入会日から最終レッスン完了までの平均日数
5. 課題完了率（%）— レビュー済み課題数 / (課題付きレッスン数 × 生徒数) × 100
6. セミナー参加率（%）— セミナー参加ユニーク生徒数 / 全生徒数 × 100
7. チャーンリスク高の人数 — 離脱リスクが「高」の生徒数（クリックで生徒一覧へ遷移）
8. 3ヶ月以内課題達成者数 — 全レッスン完了 かつ 直近3ヶ月以内に達成した生徒数

**8つの分析グラフ（2列グリッド）:**
1. 年齢分布（棒グラフ）— 10代/20代/30代/40代/50代以上の5バケット
2. 性別分布（円グラフ）— 男性/女性/その他
3. 職業分布（横棒グラフ）— 上位10職種
4. 地域分布（棒グラフ）— 上位10都道府県
5. セミナー参加推移（折れ線グラフ）— 直近6ヶ月、オンライン/現地の2系列
6. 課題停滞箇所（棒グラフ）— 未完了者が多いレッスンの上位10件
7. 課題完了日数ヒストグラム（棒グラフ）— 入会から最終課題提出までの日数、30日刻み
8. アクティブ状況推移（折れ線グラフ）— 直近12週のユニークログインユーザー数

**カラーパレット:** インディゴ/スカイ/エメラルド/アンバー/バイオレット/ピンク/レッド/ティール

### 画面3: 生徒一覧（/admin/students）
- テーブル形式で表示: 名前、メール、入会日、進捗率（プログレスバー）、チャーンリスク（色付きバッジ: 低=緑、中=黄、高=赤）、最終ログイン日
- 名前・メールアドレスでのテキスト検索
- チャーンリスクレベル（全て/高/中/低）でフィルタリング
- 各列ヘッダークリックでソート（昇順/降順トグル）
- ページネーション（1ページ20件）
- 行クリックで生徒詳細画面へ遷移

### 画面4: 生徒詳細（/admin/students/:id）
- 戻るボタン + パンくずリスト
- **プロフィールカード（左2/3）:** アバター、名前、メール、年齢・性別・職業、「入会 ○日目」表示
- **AI離脱予測スコア（右1/3）:**
  - 円形ゲージ（0〜100）、色分け: 0-30=緑、31-60=黄、61-100=赤
  - リスクレベルバッジ（LOW/MEDIUM/HIGH）
  - 計算式: (1-ログイン頻度正規化値)×40 + (課題提出間隔正規化値)×35 + (1-セミナー参加率正規化値)×25
- **3列メトリクス:** 全体進捗バー、ログイン頻度（週N回）、セミナー参加率（N%）
- **活動タイムライン:** ログイン/レッスン視聴/課題提出/セミナー申込のログを時系列表示（最大15件）
  - 各アクティビティにアイコン付き: ログイン=モニター、レッスン=再生、課題=ファイル、セミナー=カレンダー

### 画面5: レビュー一覧（/teacher/reviews）
- 「未レビュー（N件）」「レビュー済み」のタブ切替
- カード形式で一覧表示: 生徒名、アバター、レッスン名、提出日時、ステータスバッジ
- 未レビュータブにバッジで件数表示
- カードクリックでレビュー詳細へ遷移

### 画面6: レビュー詳細（/teacher/reviews/:id）
- 戻るボタン「← レビュー一覧に戻る」
- **左カラム（提出内容）:** 生徒名、レッスン名、提出日時、提出テキスト（読取専用）
- **右カラム（フィードバック）:**
  - 未レビュー時: テキストエリア（6行）+ 5段階星評価（インタラクティブ）+ 「レビューを送信」ボタン
  - レビュー済み時: フィードバック内容（読取専用）+ 星評価表示 + レビュー日時 + 「レビュー済み」バッジ

### 画面7: 学習ダッシュボード（/student/dashboard）
- タイトル「学習ダッシュボード」
- **入会日数バナー（グラデーション: インディゴ→ブルー、白文字）:**
  - 「入会 {N} 日目 · 学習を続けましょう！」
  - 全体進捗バー + パーセンテージ
- **2列カード:**
  - 左（インディゴ）: 次のレッスンカード（タイトル + 所要時間、クリックで遷移）
  - 右（ピンク）: おすすめレッスンカード
- **今週のアクション:** 活動ログリスト（最大5件）、課題提出ログに「採点」ボタン
- **コース進捗:** コース別の進捗バー + パーセンテージ、クリックでコース詳細へ遷移

### 画面8: コース一覧（/student/courses）
- カードグリッド（3列）: サムネイル、タイトル、説明（2行で切詰め）、進捗率プログレスバー
- カードクリックでカリキュラム画面へ遷移

### 画面9: カリキュラム（/student/courses/:id）
- **上部グラデーションカード:** コースタイトル + 説明 + 進捗バー（白）+ パーセンテージ
- **アコーディオン（全セクション展開済み）:**
  - セクションヘッ��ー: タイトル + 「N/M 完了」
  - レッスン行の状態表示:
    - 完了: 緑チェックマーク + タイトル + 所要時間
    - 進行中: 青再生アイコン + タイトル + 所要時間 + 左インディゴボーダー
    - 未着手: 空丸アイコン + タイトル + 所要時間
    - ロック: グレー鍵アイコン + グレーテキスト + ツールチップ「前のレッスンを完了してください」
    - 課題付きレッスン: アンバー「課題」バッジ

### 画面10: 動画レッスン（/student/courses/:cid/lessons/:lid）
- パンくずリスト: 「コース / Webマーケティング / {レッスン名}」
- **左カラム（2/3）:**
  - HTML5動画プレイヤー（アスペクト比16:9）
  - レジュームダイアログ（インディゴバナー）: 「📌 MM:SS から再開しますか？」+ 「再開」/「最初から」ボタン
    - 表示条件: 視聴秒数 > 0 かつ 未完了
  - 課題セクション（hasAssignment=trueの場合のみ）:
    - 未提出: テキストエリア + 「提出する」ボタン → 送信後トースト通知
    - 提出済み: 提出内容表示 + ステータスバッジ（レビュー待ち/レビュー済み）
    - レビュー済み: フィードバック内容 + 5段階星評価
- **右カラム（1/3）:**
  - チャプターリスト: チャプター名 + MM:SS タイムスタンプ
  - クリックで動画の該当位置にジャンプ
  - 現在再生中のチャプターがハイライト（左ボーダー + インディゴ背景）

### 画面11: セミナー一覧（/[role]/seminars）
- 「今後のセミナー」「過去のセミナー」をセクション分け
- **セミナーカード:** 日付サークル（インディゴ）、タイトル、時間・説明、場所
- **生徒ロール:** 「オンライン」/「現地参加」ボタン → 申込後は「申込済（オンライン/現地）」バッジ + 「キャンセル」ボタン
- **管理者ロール:** 申込者数（オンライン/現地の内訳）を表示
- 空の状態: 「セミナーはありません」

### 画面12: コース一覧 管理者/講師（/[role]/courses）
- 画面8と同様のカードグリッドだが読み取り専用（進捗バーなし）

## デモ用シードデータ

- 管理者1名、講師2名、生徒40名（リアルな日本人名）
- Webマーケティングスクール「GROWTH ACADEMY」
- コース: 4セクション × 3レッスン = 12レッスン（一部課題付き）
- 生徒の進捗パターン: 完了者5名/順調15名/停滞10名/未着手10名
- チャーンリスク分布: 低20名/中12名/高8名
- デモグラ分布: 年齢（20代30%/30代40%/40代20%/50代10%）、性別（男55%/女40%/他5%）、職業（会社員50%/自営業20%等）、地域（東京30%/大阪15%等）
- セミナー: 過去4件+今後3件、オンライン:現地≒6:4
- 課題提出30〜40件（レビュー済20件/未レビュー10〜20件）

## 他社デモとの差別化ポイント

| 機能 | 他社デモ（Lernen） | SchoolOS |
|------|---------------------|----------|
| 動画視聴トラッキング | 非対応 | ★ 秒単位の位置記録 + レジューム再生 |
| 動画チャプター | 非対応 | ★ タイムスタンプ + ワンクリックジャンプ |
| デモグラ分析 | 基本プロフィールのみ | ★ 8軸KPIダッシュボード |
| 課題停滞分析 | 非対応 | ★ 停滞箇所の可視化グラフ |
| 離脱予兆検知 | 未読数のみ | ★ AIスコアリング（0〜100）+ 根拠指標 |
| 入会経過管理 | 一部のみ | ★ 入会日数バナー + 進捗タイムライン |
| ステップロック | 弱い | ★ 前レッスン完了ゲーティング |
| セミナー管理 | 基本のみ | ★ オンライン/現地ハイブリッド + 申込管理 |
```
