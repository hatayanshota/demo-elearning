## 1. システム概要

### 1.1 プロジェクト名
**SchoolOS** - スクール運営に特化したオールインワンLMS（Learning Management System）

### 1.2 目的
スクール運営者向けの営業デモアプリケーション。既存の他社デモシステム（Lernenベース）では対応していない**動画視聴トラッキング**、**8軸KPIダッシュボード**、**AI離脱予測スコアリング**を備え、日本市場に特化したLMSの優位性を訴求する。

### 1.3 対象ユーザー・ロール構成

| ロール | ユーザー | 主な機能 |
|--------|----------|----------|
| 管理者（Admin） | スクール運営者 | KPIダッシュボード、生徒管理、コース管理、セミナー管理 |
| 講師（Teacher） | コース担当講師 | 課題レビュー・フィードバック、コース閲覧、セミナー管理 |
| 生徒（Student） | 受講生 | 動画学習、課題提出、セミナー申込、進捗確認 |

デモアプリのため認証は不要。トップページでロールを選択し、固定デモユーザーとして各ロールの体験を提供する。

## 2. 技術構成

### 2.1 技術スタック

| カテゴリ | 技術 |
|----------|------|
| フレームワーク | Next.js 15 (App Router + Route Handlers) |
| 言語 | TypeScript (strict mode) |
| UIコンポーネント | shadcn/ui + Radix UI |
| スタイリング | Tailwind CSS 4 |
| グラフ描画 | Recharts 3 |
| サーバー状態管理 | TanStack Query 5 |
| クライアント状態管理 | Zustand 5 |
| フォーム | React Hook Form 7 + Zod 4 |
| ORM | Prisma（Phase B で導入） |
| テスト | Vitest + React Testing Library + MSW |
| E2Eテスト | Playwright |
| DB | PostgreSQL（Docker コンテナ） |

### 2.2 アーキテクチャ

```
[フロントエンド]
  app/               ... Next.js App Router（ページルーティング）
  features/           ... 機能別モジュール（View / Container / Hook / API の3層分離）
  components/ui/      ... shadcn/ui 共通UIコンポーネント
  lib/                ... 型定義、モックデータ、ユーティリティ

[バックエンド（Phase B）]
  app/api/            ... Next.js Route Handlers
  lib/services/       ... ビジネスロジック層
  lib/repositories/   ... データアクセス層（Prisma）
  lib/validators/     ... Zodバリデーション
  prisma/             ... スキーマ・マイグレーション・シードデータ
```

### 2.3 フロントエンドアーキテクチャ（3層分離構造）

各機能は以下の3ファイルで構成:

| 層 | ファイル | 責務 |
|----|----------|------|
| View | `*.view.tsx` | 純粋なUI表示。Hooks禁止、全データはPropsで受取 |
| Container | `*.container.tsx` | HookとViewの接続のみ。UI要素の記述禁止 |
| Hook | `hooks/use*.ts` | 状態管理・ロジック集約。API通信はapi/に委譲 |

### 2.4 バックエンドアーキテクチャ（3層構造）

| 層 | 責務 |
|----|------|
| Handler（route.ts） | リクエスト受付・Zodバリデーション・レスポンス返却 |
| Service | ビジネスロジック集約。フレームワーク非依存 |
| Repository | Prisma Clientによるデータアクセス |

### 3.2 主要機能の詳細

#### KPIダッシュボード（差別化の中核機能）

8つのKPIサマリーカード:
- 在籍生徒数 / アクティブ率 / 課題完了率 / 平均課題完了日数
- セミナー参加率 / チャーンリスク高の人数 / 3ヶ月以内課題達成者数 / 新規入会者数

8つの分析グラフ:
- 年齢分布（棒グラフ）/ 性別分布（円グラフ）/ 職業分布（横棒）/ 地域分布（棒グラフ）
- セミナー参加推移（折れ線）/ 課題停滞箇所（棒グラフ）/ 課題完了日数（ヒストグラム）/ アクティブ状況（折れ線）

#### AI離脱予測スコアリング

ログイン頻度・課題提出間隔・セミナー参加率から離脱リスクを0〜100でスコア化:
```
チャーン予測スコア =
  (1 - ログイン頻度正規化値) x 40
  + (課題提出間隔正規化値) x 35
  + (1 - セミナー参加率正規化値) x 25
```

#### 動画レッスン
- HTML5 Video プレイヤー + カスタムコントロール
- チャプタージャンプ（タイムスタンプクリック）
- レジューム再生（前回視聴位置の記録・復帰ダイアログ）
- 10秒ごとの視聴位置自動保存
- 課題提出フォーム（テキスト入力 + トースト通知）

#### ステップバイステップ制御
前のレッスンが完了するまで次のレッスンをロック。セクションをまたぐ場合も前セクション全レッスン完了が条件。

## 4. データモデル

### 4.1 エンティティ関連図

```
users ─── studentProfiles (1:1)
  │
  ├── lessonProgresses ─── lessons ─── chapters
  │                          │
  ├── assignments ───────────┘
  │       └── reviews
  │
  ├── seminarRegistrations ─── seminars
  │
  └── activityLogs

courses ─── sections ─── lessons
```

### 4.2 主要テーブル（11テーブル）

| テーブル | 概要 | 主なフィールド |
|----------|------|----------------|
| users | 全ユーザー | id, email, name, role(ADMIN/TEACHER/STUDENT) |
| studentProfiles | 生徒拡張情報 | age, gender, occupation, prefecture, churnRiskScore |
| courses | コース | title, description, thumbnailUrl, sortOrder |
| sections | セクション | courseId, title, sortOrder |
| lessons | レッスン | sectionId, title, videoUrl, durationSeconds, hasAssignment |
| chapters | 動画チャプター | lessonId, title, startSeconds |
| lessonProgresses | 視聴進捗 | userId, lessonId, watchedSeconds, isCompleted |
| assignments | 課題提出 | userId, lessonId, content, status(PENDING/REVIEWED) |
| reviews | 講師レビュー | assignmentId, reviewerId, feedback, rating |
| seminars | セミナー | title, date, location, onlineUrl, capacity |
| seminarRegistrations | セミナー申込 | userId, seminarId, attendanceType(ONLINE/ONSITE) |
| activityLogs | 活動ログ | userId, type, metadata |

### 4.3 シードデータ設計

テーマ: Webマーケティングスクール「GROWTH ACADEMY」

| データ | 件数 |
|--------|------|
| 管理者 | 1名 |
| 講師 | 2名 |
| 生徒 | 40名（リアルな日本人名、デモグラ分布あり） |
| コース | 1コース（4セクション x 3レッスン = 12レッスン） |
| チャプター | 各レッスン2〜4件 |
| 課題提出 | 30〜40件 |
| レビュー | レビュー済み20件 + 未レビュー10〜20件 |
| セミナー | 過去4件 + 今後3件 |
| 活動ログ | 各生徒10〜50件 |

## 6. 他社デモシステムとの差分

| 機能 | 他社デモ（Lernen） | SchoolOS |
|------|---------------------|----------|
| 動画視聴トラッキング | 非対応 | 秒単位の視聴位置記録 + レジューム再生 |
| 動画チャプター | 非対応 | タイムスタンプ + ワンクリックジャンプ |
| デモグラ分析 | 基本プロフィールのみ | 8軸KPIダッシュボード（年齢/性別/職業/地域等） |
| 課題停滞分析 | 非対応 | 停滞箇所の可視化グラフ |
| 離脱予兆検知 | 未読数のみ | AIスコアリング（0〜100） + 根拠指標表示 |
| 入会経過管理 | 一部のみ | 入会日数バナー + 進捗タイムライン |
| ステップロック | 弱い | 前レッスン完了ゲーティング |
| セミナー管理 | 基本のみ | オンライン/現地ハイブリッド + 申込管理 |
