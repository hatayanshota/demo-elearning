# SchoolOS 開発見積書

**作成日:** 2026年3月6日
**単価:** 55,000円/人日（税別）
**前提:** 要件定義は準委任契約のため本見積りに含まない

## 1. 見積り前提条件

- 開発者1名体制を想定
- 要件定義・仕様策定は準委任契約で別途実施のため、開発工数のみを算出
- 仕様書（spec.md）確定済みの状態から開発着手
- ローカル開発環境での動作確認をゴールとする（本番デプロイは別途）
- テスト環境: Vitest + Playwright

## 8. AWSインフラ ランニングコスト試算

デモアプリを本番環境としてAWSにホスティングした場合の月額コスト試算。

### 8.1 構成図

```
[Route 53] → [CloudFront(CDN)] → [ALB] → [ECS Fargate / EC2]
                                              │
                                          [RDS PostgreSQL]
                                              │
                                          [S3 (動画/静的ファイル)]
```

### 8.2 小規模構成（生徒〜100名 / 月間PV 10,000以下）

| AWSサービス | スペック | 月額（USD） | 月額（円） |
|-------------|---------|-------------|-----------|
| EC2 | t3.small (2vCPU, 2GB) | $15.26 | 約2,300円 |
| RDS PostgreSQL | db.t4g.micro (2vCPU, 1GB) | $12.10 | 約1,800円 |
| ALB | Application Load Balancer | $16.43 | 約2,500円 |
| S3 | 50GB ストレージ + 転送 | $3.00 | 約450円 |

### 8.4 コスト比較（AWS vs Vercel + Supabase）

| 項目 | AWS（小規模） | Vercel + Supabase（Free） |
|------|--------------|--------------------------|
| 月額コスト | 約7,800円 | 0円（無料枠内） |
| スケーラビリティ | 高い（自由に構成変更可） | 中程度（プラン上限あり） |
| 運用負荷 | 高い（インフラ管理が必要） | 低い（マネージド） |
| 動画配信 | S3 + CloudFront（自前管理） | 外部サービス連携が必要 |
| 適用場面 | 本番運用・エンタープライズ | デモ・MVP・小規模運用 |

### 8.5 推奨

- **デモ目的:** Vercel + Supabase Free プラン（月額0円）で十分
- **小規模本番:** Vercel Pro ($20/月) + Supabase Pro ($25/月) = 約7,000円/月
- **エンタープライズ:** AWS構成で月額約7,800円〜20,600円
